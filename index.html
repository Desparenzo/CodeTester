What this test can and cannot prove

A passing WebAssembly or WebGPU check does not guarantee that a particular model will load. Actual limits depend on free RAM, browser memory caps, model architecture, quantization, context length and runtime support. This diagnostic deliberately does not claim to measure all available RAM or guarantee GGUF compatibility.

For a fair test, open this file in the browser you plan to use. If a feature says “not available”, try a current Chrome browser and compare results. WebGPU generally requires a secure context such as HTTPS or localhost.
